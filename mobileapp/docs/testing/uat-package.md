# Botanist mobile UAT package

**Status:** awaiting real participants. No ratings, signatures, task completions or acceptance decisions have been collected.

## Plan and participant instructions

Use an isolated test backend and synthetic plants. Invite representative Botanists and, for public browsing, a Visitor. Give each participant a test device, initial account and task list; do not coach during tasks except to prevent unsafe action. Observe completion, time if consented, assistance, errors and comments. Collect no real protected-species coordinates in screenshots. Acceptance requires users to complete the critical submission, correction and retrieval tasks and explicitly sign the decision; thresholds should be agreed before sessions.

## Tasks

| ID | Task | Expected outcome |
|---|---|---|
| UAT-B01 | Login and find an approved Plant/Species | Correct record reached without help |
| UAT-B02 | Search/filter Plants and Species | Intended record or clear empty result |
| UAT-B03 | Save and resume a Plant draft with photo/GPS | Values and photo selection preserved |
| UAT-B04 | Submit an Observation for a selected Plant | Pending Observation appears under correct Plant |
| UAT-B05 | Open a correction and submit an update | Officer feedback visible; updated request tracked |
| UAT-B06 | Scan a QR and inspect role-appropriate result | Correct safe alert or published record |
| UAT-B07 | Read a notification and navigate to record | Correct destination and read state |
| UAT-B08 | Change language/text size and complete a long form | Interface remains understandable and reachable |

## Questionnaire (circle 1–5; 1 difficult, 5 easy)

Rate navigation, finding information, search/filter clarity, draft recovery, submission steps, correction feedback, notifications, readability and overall satisfaction. Free text: What blocked you? What was confusing? What should change? Would you use this for fieldwork, and why?
